# 20251006：否定抽取规则修复——裸"别/不要"不再触发

## 背景

20251005 的探索实验（docs/experiments/20251005-extraction-pr.md）里，
"别/不要"型规则在 12 条灰色探针上 precision 只有 0.20，全场最拉胯：
4 条误抽全是一次性指令（"别走这条路""别急""不要急"），唯一的 TP 是
"以后别再给我放广告了"。

当时的设计是"宁可误抽不漏记"：0.65 全场最低置信度 + Memory Gate 人工
确认兜底。但想了一层：Gate 是最后一道，不是垃圾桶。座舱里导航指令
高频出现（"别走这条路""慢点"），每条都弹确认，用户点两天就麻木乱点，
Gate 的确认质量反而被噪音稀释。这是安全论证，不只是"抽取层太脏"。

约束：① fixture 里"以后别给我放广告"必须继续抽（kind=auth，
min_confidence 0.6，已提交的地面真值，不能悄悄改）；② 确定性优先，
不许上 LLM 做语义区分；③ 不动 Gate/store/recall 的语义。

## 候选方案

1. **抑制裸"别/不要"，只保留持久型否定**（以后别/以后不要/别再/不要再）。
   代价：极少数用户只说裸"别X"表达的真·稳定禁忌会被漏掉——但稳定禁忌
   的自然说法是"我不喜欢X"（已有 0.75 规则）或"以后别X"，实际损失很小。
2. **记为负向偏好**（加 polarity 字段，"别走高速"→讨厌高速）。
   代价：Gate、store、recall 全链路要改语义，是 feature 不是 fix；而且
   裸"别X"在座舱里八成是一次性指令，记成负向偏好大部分是错的——数据
   不诚实。否决。
3. **维持现状**（0.65 + Gate 兜底）。
   代价：见背景——高频噪音削弱 Gate。这次修的就是这个，否决。
4. （试过，放弃）**按名词类别启发式区分**："放广告"→媒体→稳定，
   "走这条路"→路线→一次性。写了两行就删了：脆皮规则，"以后别去那家
   店"（地点但稳定）立刻反例；规则表已经 9 条，再加特例就是补丁摞补丁。

## 选择

方案 1：否定触发词从`以后别|别再|不要|别`收紧为
`以后别|以后不要|别再|不要再`。

## 为什么

看 probe 表时发现的规律：误抽和正例的区别根本不是"别/不要"本身，
而是**有没有持久性标记**。4 条误抽全是裸"别/不要"，
2 条正例（"以后别再给我放广告了"、fixture 的"以后别给我放广告"）
全带"以后/再"。所以分界线就画在用户亲口说的持久性标记上：
**抽取层只认用户说出口的"以后/再"，不替用户脑补持久性。**

几个当时纠结的点，如实记：

- **"今天堵车，以后别走这条路"怎么判？** 旧探针标"不抽"（事件型）。
  但"以后别放广告"必须抽，正则分不清"放广告"和"走这条路"哪个是真
  稳定（方案 4 已否决）。最后决定：有"以后"就抽，0.65 让 Gate 问人。
  用户亲口说了"以后"，抽取层再替他判断"这次不算"，是越权。
  探针标注本来就是主观的（实验文档自己写了"不是 ground truth"），
  这次改判写进了 eval/extraction_pr.py 的备注。
- **0.65 为什么不动？** 即使有"以后"，也分不清真禁忌和带情绪的一次性
  抱怨。0.65 全场最低就是"这条我最没把握"的意思，动它没有证据支撑。
  面试官问"为什么是 0.65"：因为它是排序垫底的占位值，不是算出来的；
  真正的刻度等以后有了大规模标注数据再校准——现在 22 条 fixture 的
  体量，任何"精确调参"都是自欺。
- **触发词为什么是这四个？** "以后别/别再"是 probe 和 fixture 里真实
  出现过的；"以后不要/不要再"是同样结构的自然说法，顺手收了。
  "以后都别""再也别"罕见，不收——清单保持短，注释里没写就是没覆盖，
  诚实比完备重要。
- **kind 为什么还是 auth？** fixture 地面真值写的是 auth，"别放广告"
  语义上更像"禁忌"不是"授权"，但改 kind 要连 fixture 一起改，这次
  的任务是修误抽不是重定分类，先不动，留待以后。

## 对 eval 的影响

- fixture 从 16 条扩到 23 条：新增 4 条反例（"别走这条路""别急，
  慢慢来""不要急""慢点，别走这条路"→ 一条不抽）+ 3 条正例
  （"别再给我导航走高速""不要再放广告了""以后不要给我放广告"→ 抽，
  kind=auth，conf 0.65）。
- `test_confidence_ordering` 里 forbid 用例换成"以后别给我放广告"
  （裸"别"已不触发）；新增 `test_bare_negation_suppressed` 显式回归。
- `eval/extraction_pr.py` 探针"今天堵车，以后别走这条路"改判为抽；
  `tests/test_extraction_pr.py` 里"别/不要型 precision 0.20"的旧断言
  重写为新行为回归（5 探针全对，tp=2 fp=0）。
  注意：`docs/experiments/20251005-extraction-pr.md` 是 10-05 的历史
  记录，数字保留不动；新旧对比以本决策为准。
- 图级行为变化：`memory_capture` 对裸"别/不要"指令不再产出候选，
  extracted 计数下降——这是修 bug，不是 regression，确认过没有
  eval 轨迹依赖裸"别"抽取（dataset_v0.jsonl 无此类用例）。
