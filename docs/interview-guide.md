# TripPilot 出行访谈提纲（v1）

> 目的只有一句话：**收集 12–15 个真实原始任务**，用来派生下一批 eval 用例。
> 不需要写得多漂亮——原话、场景、没办成的细节记下来就行，派生和写 JSONL 是构建流水线的活。

## 怎么访：轻量、6 次、每次 10 分钟

- **对象**：自己也算（回溯最近 10 次真实出行），再找 3–5 个朋友聊（开车或打车时用语音助手的都行）。
- **形式**：一次聊 2–3 个任务，全程 10 分钟。别搞成问卷审问，顺着"上次你开车去 XX 干嘛来着"聊。
- **记录**：用下面模板，手机备忘录逐条记。**原话优先**，转述其次，别润色成书面语。
- **诚实线**：访谈里不提"我们有个座舱 Agent 项目"，避免对方迎合；聊的是"出行习惯"，不是产品测试。

## 6 次分工（覆盖维度，别重复采样）

| # | 场景 | 重点抓的维度 |
|---|------|-------------|
| 1 | 通勤（自己） | 时间压力下的多步任务（路线+天气+提醒） |
| 2 | 接人/接机/接高铁（自己或朋友） | 动态变更：航班晚点、改地点，中途改计划 |
| 3 | 带家人出游（朋友） | 多偏好记忆：老人要厕所近、孩子要充电口——下次还提不提 |
| 4 | 办事跑腿：银行/医院/4S 店（朋友） | 行驶中的限制：开车时能不能办、哪些事必须停下 |
| 5 | 购物/吃饭找地儿（自己或朋友） | 模糊澄清："去西站"到底是哪个西站，追问有没有点名 |
| 6 | 翻车现场：导航错了/忘带东西/工具没信号（谁都行） | 失败恢复：当时怎么补救的，Agent 该怎么兜 |

## 问题清单（每次访谈照着问，顺序随意）

**开场（1 分钟）**
1. 上次开车/打车出门是去干嘛？从哪到哪？

**任务还原（5 分钟，每个任务都问）**
2. 出门前你脑子里那句话原话是怎么说的？（比如"明天下午去中关村面试，看看几点出门"）
3. 这件事拆成几步？你实际动手查/点了什么？（路线、天气、停车、提醒、电话……）
4. 哪一步最烦？如果有个助手能替你做，你希望它先做哪一步？

**追问维度（4 分钟，挑相关的问）**
5. **澄清**：有没有过它听错/你说得模糊的时候？你希望它怎么追问你？（点名选项 vs 直接猜）
6. **偏好**：有没有"每次都这么说"的习惯？（比如"别走高速""先找停车场"）你希望它记住吗？哪些**不想**被记住？（敏感偏好标注★）
7. **行驶中**：开车的时候你会让它干嘛？有没有哪件事你觉得"开车时绝对不该干"？
8. **翻车**：有没有它/导航/手机掉链子的时候？你当时怎么补救的？

## 记录模板（每条任务复制一份）

```
任务编号：I-01
受访人：本人 / 朋友A（关系：同事；脱敏后记）
场景：通勤 / 接人 / 出游 / 办事 / 找地儿 / 翻车
原话："________"
时间压力：赶时间 / 不赶
车况：自己开 / 副驾 / 打车
实际步骤：1.___ 2.___ 3.___
最烦的一步：___
希望被记住的偏好：___
★不想被记住的：___
澄清瞬间（有就记）：___
翻车瞬间（有就记）：___
可派生 eval 方向：记忆 / 澄清 / 行驶降级 / 恢复 / 多工具链
```

## 交接标准

- 6 次访谈做完，把模板条目发给构建流水线（或直接扔 docs/ 下 `interview-notes/`）。
- 目标：**12–15 个原始任务**，其中至少 3 条带"澄清瞬间"、2 条带"翻车瞬间"——这两类是现在 eval 最缺的真实输入。
- 合成/派生上限不变：`real_recalled` 打底，合成类 ≤ 3/12 的比例约束继续沿用（见 `decisions/20251005-eval-dataset-v1.md`）。
